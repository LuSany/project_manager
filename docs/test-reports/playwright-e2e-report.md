## 发现的问题及修复

### 问题 1: Dashboard 登录格式不匹配 ✅ 已修复

**问题描述**: 登录 API 返回 `data.users`，前端期望`data.user`

**影响**: 登录后 Dashboard 无法获取用户信息

**修复**:

- 文件: `src/app/api/v1/auth/login/route.ts`
- 修改: 将返回字段从 `users` 改为`user`
- 提交: `9c6dcb3`

**验证**: ✅ 登录功能测试通过

---

### 问题 2: Prisma uploaderId 字段类型错误 ✅ 已修复

**问题描述**: 添加 `uploaderId` 字段后 Prisma Client 类型不兼容

**影响**: 构建失败，无法创建评审材料

**修复**:

1. 文件: `src/app/api/v1/reviews/[id]/materials/route.ts`
   - 移除重复的 `users: { connect }` 关系定义
   - 直接使用 `uploaderId` 字段
2. 文件：`src/app/api/v1/reviews/route.ts`
   - 在创建 materials 时添加 `uploaderId: user.id`
3. 重新生成 Prisma Client

**验证**: ✅ 构建成功，P0/P1 测试通过

---

### 问题 3: Next.js Turbopack 缓存错误 ✅ 已修复

**问题描述**: `.next` 目录缓存损坏，导致页面无法加载

**影响**: E2E 测试失败，页面显示运行时错误

**修复**:

```bash
rm -rf .next
npm run build
```

**验证**: ✅ 所有静态页面正常加载
