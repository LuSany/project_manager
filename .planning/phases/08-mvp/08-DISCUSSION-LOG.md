## 设备类型结构

| Option     | Description                                                            | Selected |
| ---------- | ---------------------------------------------------------------------- | -------- |
| 固定字段   | 名称、型号、位置、描述、负责人。简单直观，易于实现和维护，MVP 推荐     | ✓        |
| 自定义属性 | 允许管理员为每种设备类型添加自定义字段。更灵活，适合实验室多种设备类型 |          |

**User's choice:** 固定字段 (推荐)

---

## 预定交互方式

| Option     | Description                                          | Selected |
| ---------- | ---------------------------------------------------- | -------- |
| 选择时间段 | 用户选择具体开始和结束时间，直观但需要手动计算时长   |          |
| 选择时长   | 用户选择开始时间和持续时长，更灵活但需要验证结束时间 |          |
| 日历拖拽   | 类似日历拖拽，从设备可用时间表中直接选择连续时段     | ✓        |

**User's choice:** 日历拖拽

---

## 冲突检测策略

| Option   | Description                              | Selected |
| -------- | ---------------------------------------- | -------- |
| 精确匹配 | 完全禁止重叠，提示具体冲突的预定         | ✓        |
| 允许警告 | 允许重叠但显示警告，用户可选择强制预定   |          |
| 允许重叠 | 允许预定，系统记录但不影响，适合紧急情况 |          |

**User's choice:** 精确匹配

---

## 设备列表展示

| Option   | Description                                  | Selected |
| -------- | -------------------------------------------- | -------- |
| 表格视图 | 适合管理员查看所有设备、筛选、排序           | ✓        |
| 卡片网格 | 卡片展示设备图片和状态，适合用户选择可用设备 |          |
| 左右分栏 | 左侧卡片选择设备，右侧日历查看/选择时间      |          |
| 日历视图 | 日历视图中直接显示设备，按行排列             |          |

**User's choice:** 表格视图

---

## 状态流转流程

| Option            | Description                                            | Selected |
| ----------------- | ------------------------------------------------------ | -------- |
| 简单3状态         | 可用 → 维护中 → 已停用，MVP 推荐                       |          |
| 4状态（含使用中） | 可用 → 使用中 → 维护中 → 已停用，适合贵重设备          |          |
| 完整状态机        | 可用 → 已预约 → 使用中 → 维护中 → 已停用，完整生命周期 | ✓        |

**User's choice:** 完整状态机
