## Device Management-Specific UX

### Device List View

- Table with columns: Name, Model, Location, Status, Owner, Actions
- Filter by status, location
- Sort by name, status, last updated

### Device Booking Flow

- Calendar shows device availability (similar to Phase 4 calendar view)
- Drag to select time range
- Exact match conflict detection - no overlap allowed
- Conflict shows specific conflicting booking info

### Device Status Transitions

- Available → Reserved (user books)
- Reserved → In Use (booking starts)
- In Use → Available (booking ends)
- Available → Maintenance (admin sets)
- Maintenance → Available (admin sets)
- Any → Disabled (admin sets - no new bookings)
