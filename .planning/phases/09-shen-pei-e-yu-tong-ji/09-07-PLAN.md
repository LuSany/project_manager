<task type="auto">
  <name>Task 4: 修复审批记录查询逻辑</name>
  <files>src/app/api/v1/approval-records/route.ts</files>
  <action>
    修复审批记录API中PENDING状态查询无法返回数据的问题：

    问题分析（第55-65行）：
    ```typescript
    if (status === 'PENDING') {
      recordsWhere.bookingId = { in: pendingBookingIds }
      const approverConfigs = await db.approval_configs.findMany()
      const pendingRecords = await db.approval_records.findMany({
        where: { approverId: user.id },
        select: { bookingId: true },
      })
      const processedBookingIds = pendingRecords.map((r) => r.bookingId)
      recordsWhere.bookingId = {
        in: pendingBookingIds.filter((id) => !processedBookingIds.includes(id)),
      }
    }
    ```

    问题：
    1. 当前逻辑查询当前用户已处理的审批记录，然后过滤掉已处理的
    2. 但 approval_records 表只有 APPROVED/REJECTED/FORWARDED 操作记录
    3. 对于新创建的待审批预订，没有任何审批记录，应该显示给审批人

    修复方案：
    1. PENDING 状态应该返回：
       - 所有状态为 PENDING_APPROVAL 的预订
       - 且当前用户是该设备类型的审批人
       - 且当前用户尚未处理该预订

    2. 具体修改：
       - 查询当前用户可审批的设备类型（通过 approval_configs）
       - 查询这些设备类型的 PENDING_APPROVAL 预订
       - 过滤掉当前用户已处理的预订

    3. 新逻辑：
       ```typescript
       if (status === 'PENDING') {
         // 获取当前用户可审批的设备类型
         const myApprovalConfigs = await db.approval_configs.findMany({
           where: { approverIds: { contains: user.id } },
           select: { deviceTypeId: true },
         })
         const myDeviceTypes = myApprovalConfigs.map(c => c.deviceTypeId)

         // 获取这些设备类型的待审批预订
         const pendingBookings = await db.bookings.findMany({
           where: {
             status: 'PENDING_APPROVAL',
             devices: { typeId: { in: myDeviceTypes } }
           },
           select: { id: true, devices: { select: { typeId: true } } }
         })

         // 过滤已处理的
         const processedBookingIds = await db.approval_records.findMany({
           where: { approverId: user.id },
           select: { bookingId: true }
         }).then(r => r.map(x => x.bookingId))

         const availableBookingIds = pendingBookings
           .filter(b => !processedBookingIds.includes(b.id))
           .map(b => b.id)

         recordsWhere.bookingId = { in: availableBookingIds }
       }
       ```

    注意：approverIds 是 JSON 字符串，contains 查询可能不精确。
    更好的方案是解析 JSON 后检查用户是否在审批人列表中。
  </action>
