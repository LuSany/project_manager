## 审批流程设计

### 审批链模式

| Option                | Description                                    | Selected |
| --------------------- | ---------------------------------------------- | -------- |
| 单级 + 可选多级串行   | 大多数场景一位审批人，贵重设备可配置多级审批链 | ✓        |
| 固定多级串行          | 所有预定必须经过固定审批链                     |          |
| 混合模式（串行+会签） | 支持串行和并行审批，最灵活但实现复杂           |          |

**User's choice:** 单级 + 可选多级串行
**Notes:** 覆盖常见场景，实现复杂度适中

### 审批人配置方式

| Option               | Description                      | Selected |
| -------------------- | -------------------------------- | -------- |
| 按设备类型配置审批人 | 每种设备类型配置自己的审批人列表 | ✓        |
| 按项目配置审批人     | 项目级别设置审批人               |          |
| 全局统一审批人       | 全局设置审批人                   |          |

**User's choice:** 按设备类型配置审批人
**Notes:** 灵活适应不同设备的管理需求

### 审批操作类型

| Option                        | Description                | Selected |
| ----------------------------- | -------------------------- | -------- |
| 通过 + 驳回 + 转交            | 审批人可批准、驳回、或转交 | ✓        |
| 通过 + 驳回                   | 只支持通过和驳回           |          |
| 全功能（通过+驳回+转交+加签） | 支持加签（添加临时审批人） |          |

**User's choice:** 通过 + 驳回 + 转交
**Notes:** 转交功能处理审批人无法决定的情况

### 审批后状态变化

| Option          | Description                    | Selected |
| --------------- | ------------------------------ | -------- |
| 审批通过→已确认 | 用户开始使用时手动确认"使用中" | ✓        |
| 审批通过→使用中 | 预定直接进入使用中状态         |          |

**User's choice:** 审批通过→已确认
**Notes:** 增加"已确认"中间状态，用户手动确认使用开始

### 审批界面呈现

| Option       | Description                          | Selected |
| ------------ | ------------------------------------ | -------- |
| 独立审批页面 | 显示所有待审批预定，可逐个或批量处理 | ✓        |
| 嵌入预定列表 | 预定列表页中加"待审批"筛选器         |          |
| 详情页内操作 | 审批信息在预定详情中展示             |          |

**User's choice:** 独立审批页面
**Notes:** 审批人需要集中处理多个审批项

### 审批备注要求

| Option             | Description          | Selected |
| ------------------ | -------------------- | -------- |
| 可选备注，驳回必填 | 确保驳回有明确理由   | ✓        |
| 无备注             | 审批时无需填写       |          |
| 必填备注           | 通过和驳回都必须填写 |          |

**User's choice:** 可选备注，驳回必填

### 审批超时处理

| Option             | Description              | Selected |
| ------------------ | ------------------------ | -------- |
| 超时自动通过       | 避免流程阻塞             |          |
| 超时提醒不自动通过 | 提醒审批人但保持审批严谨 | ✓        |
| 无超时机制         | 完全依赖人工             |          |

**User's choice:** 超时提醒不自动通过

### 审批链配置位置

| Option             | Description                        | Selected |
| ------------------ | ---------------------------------- | -------- |
| 设备类型配置页内嵌 | 管理员配置设备类型时同时设置审批人 | ✓        |
| 独立审批流配置页   | 单独的审批流管理页面               |          |

**User's choice:** 设备类型配置页内嵌

### 预定与审批关系

| Option         | Description              | Selected |
| -------------- | ------------------------ | -------- |
| 先审批后使用   | 预定必须审批通过才能使用 | ✓        |
| 免审批直接使用 | 所有预定直接生效         |          |
| 按设备类型决定 | 部分设备类型需要审批     |          |

**User's choice:** 先审批后使用

### 取消策略

| Option                   | Description        | Selected |
| ------------------------ | ------------------ | -------- |
| 可随时取消               | 审批中也可取消预定 | ✓        |
| 审批通过后不能取消       | 需联系管理员       |          |
| 审批通过后可取消但需原因 | 需要填写取消原因   |          |

**User's choice:** 可随时取消

### 审批通知对象

| Option            | Description                            | Selected |
| ----------------- | -------------------------------------- | -------- |
| 双向通知          | 审批人收到申请通知，申请人收到结果通知 | ✓        |
| 仅结果通知        | 只通知申请人审批结果                   |          |
| 双向 + 抄送负责人 | 额外抄送给项目负责人                   |          |

**User's choice:** 双向通知

### 设备类型子配额

## 预警通知机制

### 预警阈值设定

| Option                | Description                    | Selected |
| --------------------- | ------------------------------ | -------- |
| 固定三级 50%/80%/100% | 覆盖正常使用、接近超限、已超限 | ✓        |
| 管理员自定义阈值      | 可按项目定制                   |          |
| 单次 80% 预警         | 仅发送一次预警                 |          |

**User's choice:** 固定三级 50%/80%/100%

### 通知方式

| Option            | Description                        | Selected |
| ----------------- | ---------------------------------- | -------- |
| 站内通知          | 通过现有 createNotification() 发送 | ✓        |
| 站内 + 邮件双通道 | 同时发送两种通知                   |          |
| 仅邮件通知        | 只通过邮件                         |          |

**User's choice:** 站内通知

### 通知对象

| Option              | Description              | Selected |
| ------------------- | ------------------------ | -------- |
| 项目成员 + 项目经理 | 让相关人员都了解配额情况 | ✓        |
| 仅项目经理          | 只通知负责人             |          |
| 仅预定者            | 只通知申请人             |          |
| 项目经理 + 管理员   | 额外通知管理员           |          |

**User's choice:** 项目成员 + 项目经理

### 通知内容

| Option       | Description                                   | Selected |
| ------------ | --------------------------------------------- | -------- |
| 关键数据摘要 | 项目名、已用/总配额、剩余百分比、超限日期预估 | ✓        |
| 简单提示     | 仅提示"配额即将用完"                          |          |
| 详细报表     | 各设备类型用量分解                            |          |

**User's choice:** 关键数据摘要

### 预警触发时机

| Option              | Description              | Selected |
| ------------------- | ------------------------ | -------- |
| 预定创建时触发      | 每次新预定创建时检查配额 | ✓        |
| 每日定时检查        | 每天定时检查所有项目配额 |          |
| 实时 + 定时双重检查 | 两种方式都支持           |          |

**User's choice:** 预定创建时触发

### 重复通知策略

| Option           | Description      | Selected |
| ---------------- | ---------------- | -------- |
| 每阈值只通知一次 | 避免重复打扰     | ✓        |
| 每次预定都通知   | 每次都检查并通知 |          |
| 每阈值每天一次   | 每天最多通知一次 |          |

**User's choice:** 每阈值只通知一次
