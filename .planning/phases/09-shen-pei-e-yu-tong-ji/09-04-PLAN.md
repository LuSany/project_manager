    **创建 `src/app/api/v1/equipment-stats/route.ts`：**

    单一 GET 端点，通过 `type` 参数区分三种查询模式（per D-25 三个维度）：

    ```typescript
    import { NextRequest, NextResponse } from 'next/server'
    import { db } from '@/lib/db'

    // GET /api/v1/equipment-stats?type={projectHours|deviceUtilization|usageRecords}
    // 公共参数:
    //   - startDate, endDate: 时间范围（per D-28 月度 + 自定义）
    //   - projectId: 项目筛选
    //   - page, pageSize: 分页（usageRecords 模式）
    ```

    **模式 1: type=projectHours（项目机时统计，per D-14）**
    - 查询时间范围内的 COMPLETED/IN_PROGRESS bookings
    - 按 projectId 分组聚合使用小时数
    - 返回: `[{ projectId, projectName, usedHours, bookingCount, trend: [{date, hours}] }]`
    - trend 为按日期的使用量趋势（per D-26 折线图数据）
    - 如果指定 projectId，返回该项目的每日使用趋势

    **模式 2: type=deviceUtilization（设备使用率，per D-15）**
    - 计算每台设备在时间范围内的使用率 = 实际使用时间 / 总可用时间 × 100%
    - 按设备分组
    - 返回: `[{ deviceId, deviceName, typeName, utilization, totalBooked, totalAvailable }]`
    - per D-26: 柱状图数据格式

    **模式 3: type=usageRecords（使用记录查询，per D-16, D-29）**
    - 支持筛选参数: projectId, deviceId, userId, startDate, endDate, status
    - 分页返回
    - 返回: `{ items: [{id, deviceName, typeName, userName, projectName, startTime, endTime, status, hours}], total, page, pageSize }`
