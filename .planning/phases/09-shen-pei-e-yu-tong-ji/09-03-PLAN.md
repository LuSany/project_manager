export interface ProjectHoursParams {

endDate?: string

}

export interface UsageRecordItem {

endTime: string

}

2. **Create stats library** `src/lib/equipment-stats.ts` per D-14, D-15, D-16, D-26, D-27, D-28, D-29:

Implement `aggregateProjectHours(params)`:
- Query bookings with status IN (RESERVED, IN_PROGRESS, COMPLETED) grouped by project
- Filter by current month (or provided month param format 'yyyy-MM')
- Calculate hours as `(endTime - startTime) / 3600000` per D-23 (actual usage)
- Only count bookings where status is RESERVED/IN_PROGRESS/COMPLETED (not CANCELLED/PENDING_APPROVAL)
- Return top N projects sorted by totalHours desc per D-14

Implement `calculateDeviceUtilization(params)`:
- Calculate used hours per device from bookings in date range per D-15
- Available hours = days in range * working hours per day (8:00-20:00 = 12h) per D-28
- Utilization = usedHours / availableHours * 100
- Generate daily trend (hours per day) for line chart per D-26
- Filter by deviceTypeId if provided per D-25

Implement `queryUsageRecords(params)`:
- Query bookings with includes (device, deviceType, user, project) per D-16
- Apply filters: projectId, deviceId, userId, date range per D-29
- Support pagination with page/pageSize per D-29
- Default sort by startTime desc
- Calculate hours for each record per D-23

Implement `generateExcelBuffer(params)`:
- Use `xlsx` library (NOT report-generator.ts per D-27)
  - Import pattern: `import * as XLSX from 'xlsx'`
- Create workbook with headers and data rows per D-27
  - Headers: 项目, 设备, 设备类型, 用户, 开始时间, 结束时间, 状态, 使用时长(小时)
  - Return Buffer for streaming download
  - Set filename with timestamp: `equipment-stats-${Date.now().toISOString().slice(0,10)}.xlsx`
  - Handle empty data (return empty workbook with headers only) per D-27

- Export types: 'project-hours', 'device-utilization', 'usage-record' per D-27

Each function should handle the DB query and response formatting using the established `success()`/`error()` pattern from `src/lib/api/response.ts`.
