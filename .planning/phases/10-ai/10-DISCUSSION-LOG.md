## AI 风险识别交互

| Option             | Description                                     | Selected |
| ------------------ | ----------------------------------------------- | -------- |
| 项目详情页手动触发 | 在项目风险页面添加"AI 分析"按钮，用户点击后触发 | ✓        |
| 独立 AI 分析页面   | 创建独立的 /ai/risk-analysis 页面               |          |
| 风险列表页集成     | 在现有风险列表页顶部添加 AI 分析入口            |          |

| **用户's choice:** 项目详情页手动触发
| **Notes:** 錆成现有风险页面，不需要新建独立页面

| Option             | Description                                               | Selected |
| ------------------ | --------------------------------------------------------- | -------- |
| 建议列表，手动确认 | AI 返回建议列表，用户逐条审核并决定是否创建为正式风险记录 | ✓        |
| 自动创建草稿       | AI 自动创建风险记录（标记为 AI 识别），用户后续审核修改   |          |
| 仅通知不创建       | AI 分析结果仅作为通知发送，不自动创建任何记录             |          |

| **User's choice:** 建议列表，手动确认
| **Notes:** 用户保持最终控制权，AI 不自动创建记录

## AI 评审员角色

| Option            | Description                                                   | Selected |
| ----------------- | ------------------------------------------------------------- | -------- |
| AI_REVIEWER 角色  | AI 添加为特殊参与者类型，自动投票但标记为 AI 生成，不影响共识 | ✓        |
| AI 作为观察者     | AI 使用 OBSERVER 角色，仅提供分析报告和评论                   |          |
| AI 作为普通评审员 | AI 使用 REVIEWER 角色，与人类评审员平等                       |          |

| **User's choice:** AI_REVIEWER 角色
| **Notes:** 新增枚举类型，独立于现有角色

| Option   | Description                                        | Selected |
| -------- | -------------------------------------------------- | -------- |
| 自动触发 | 评审创建后 AI 自动接收材料、分析、提交投票         | ✓        |
| 手动触发 | 每次需要 AI 投票时，由主持人手动点击"请求 AI 分析" |          |

| **User's choice:** 自动触发
| **Notes:** 可在 AI 配置中开关此功能

## 定时风险扫描

| Option         | Description                          | Selected |
| -------------- | ------------------------------------ | -------- |
| 可配置项目列表 | 管理员在 AI 配置页选择参与扫描的项目 | ✓        |
| 全部项目       | 所有项目都参与扫描                   |          |
| 项目级开关     | 仅标记为"启用 AI 监控"的项目         |          |

| **User's choice:** 可配置项目列表

| Option    | Description                     | Selected |
| --------- | ------------------------------- | -------- |
| 每日      | 每天扫描一次                    |          |
| 每周      | 每周扫描一次                    |          |
| 每 8 小时 | 每 8 小时扫描一次，及时发现风险 | ✓        |

| **User's choice:** 每 8 小时

| Option          | Description                                      | Selected |
| --------------- | ------------------------------------------------ | -------- |
| 通知 + 建议列表 | 发现新风险时发通知，不自动创建记录，用户手动处理 | ✓        |
| 自动创建草稿    | 自动创建风险草稿（标记 AI 识别）                 |          |
| 仅通知          | 仅发通知，无创建功能                             |          |

| **User's choice:** 通知 + 建议列表
| **Notes:** 与手动触发方式一致，用户确认后才创建记录
