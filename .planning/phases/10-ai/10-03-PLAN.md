   - 状态：`draft`（string | null）、`isGenerating`、`isEditing`、`editedDraft`

   - 草案以 Markdown 渲染展示（使用 `whitespace-pre-wrap` 或简单的 Markdown 渲染）
   - 主持人可编辑：`isModerator` 为 true 时显示"编辑"按钮，切换为 textarea 编辑模式
   - "确认决议"按钮（仅主持人可见）：确认后调用 API 保存最终版本
   - 使用 Card 包裹，标题"AI 决议草案" + Badge 标记"AI 生成"
