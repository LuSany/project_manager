    SVG 渲染逻辑：

    **起点和终点计算（按依赖类型 per D-07）：**
    - FINISH_TO_START: 起点 = source 右端中点 (x+width, y+height/2)，终点 = target 左端中点 (x, y+height/2)
    - START_TO_START: 起点 = source 左端中点 (x, y+height/2)，终点 = target 左端中点 (x, y+height/2)
    - FINISH_TO_FINISH: 起点 = source 右端中点，终点 = target 右端中点
    - START_TO_FINISH: 起点 = source 左端中点，终点 = target 右端中点

    **折线路径计算（直角折线 per D-07）：**
    使用 SVG <path> 的 L (lineto) 命令构建折线：
    1. 从起点向右/左延伸 10px（间隙）
    2. 垂直到目标 y 坐标（如果需要）
    3. 水平到终点 x（如果需要）
    4. 到达终点

    具体 path 算法：
    ```
    M startX startY
    L midX1 startY     // 水平延伸到中间
    L midX1 endY       // 垂直到目标行
    L endX endY        // 水平到终点
    ```

    处理特殊情况：
    - 目标在源左边：折线向上或向下绕行
    - 同一行任务：向上绕行再回到目标

    **1. 创建关键路径算法（src/components/tasks/gantt/GanttCriticalPath.ts）**

    Per D-11（关键路径高亮，自动计算最长路径）：

    ```typescript
    /**
     * 计算关键路径
     * 使用最长路径算法：在任务依赖图中找到从起点到终点的最长路径
     * 关键路径上的任务延迟会导致整个项目延迟
     */
    export function calculateCriticalPath(
      tasks: GanttTask[],
      dependencies: GanttDependency[]
    ): Set<string>
    ```

    算法实现：
    1. 构建邻接表：从 dependencies 构建 sourceTaskId → targetTaskId 的有向图
    2. 找到所有入度为 0 的节点（起始任务）
    3. 使用拓扑排序 + 动态规划计算每个节点的最早完成时间：
       - 每个任务的持续时间 = (dueDate - startDate) 的天数
       - 最早开始时间 = max(所有前置任务的最早完成时间)
       - 最早完成时间 = 最早开始时间 + 持续时间
    4. 反向追踪从最晚完成的任务回溯，找到最长路径
    5. 返回关键路径上所有任务 ID 的 Set

    辅助函数：
    ```typescript
    /** 获取任务持续时间（天） */
    function getTaskDuration(task: GanttTask): number

    /** 拓扑排序 */
    function topologicalSort(
      tasks: GanttTask[],
      adjacency: Map<string, string[]>
    ): string[]

    /** 反向追踪关键路径 */
    function backtrackCriticalPath(
      endTaskId: string,
      earliestStart: Map<string, number>,
      reverseAdjacency: Map<string, string[]>,
      taskDuration: Map<string, number>
    ): string[]
    ```

    边界情况处理：
    - 无依赖时返回空 Set
    - 循环依赖检测：拓扑排序时检测到环则跳过循环部分
    - 任务缺少日期时持续时间为 1 天（最小值）
