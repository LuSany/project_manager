## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                     |
| ----- | ----- | ------------------------- |
| xs    | 4px   | Icon gaps, inline padding |
| sm    | 8px   | Compact element spacing   |
| md    | 16px  | Default element spacing   |
| lg    | 24px  | Section padding           |
| xl    | 32px  | Layout gaps               |
| 2xl   | 48px  | Major section breaks      |
| 3xl   | 64px  | Page-level spacing        |

**Exceptions:**

- Gantt row height: 36px (h-9) — 任务条高度，平衡信息量和可读性
- Gantt task bar height: 24px (h-6) — 任务条内部显示高度
- Left panel width: 30% (固定比例)
- Right timeline width: 70% (固定比例)
- Timeline cell width (day): 48px (w-12)
- Timeline cell width (week): 120px (w-30)
- Timeline cell width (month): 200px (w-52)
- Time scale header height: 48px (h-12)
- Dependency line stroke: 2px
- Touch targets: minimum 44x44px (accessibility)

**Source:** Inherited from Phase 1-4 UI-SPECs; gantt-specific values from D-01 to D-14, D-06 from CONTEXT.md.

## Color

| Role            | Value                              | Usage                           |
| --------------- | ---------------------------------- | ------------------------------- |
| Dominant (60%)  | `var(--background)`                | Page backgrounds, main surfaces |
| Secondary (30%) | `var(--card)` / `var(--popover)`   | Task list panel, timeline area  |
| Accent (10%)    | `var(--primary)` / `var(--accent)` | Interactive elements            |
| Destructive     | `var(--destructive)`               | Destructive actions only        |

**Accent reserved for:**

- Today indicator (vertical line in timeline)
- Primary action buttons (新建任务, 保存)
- Focus rings on interactive elements
- Hover states on task bars

**Priority Colors (for task bars):**

| Priority    | Bar Color       | Usage                         |
| ----------- | --------------- | ----------------------------- |
| 高 (HIGH)   | `bg-red-500`    | High priority task bar fill   |
| 中 (MEDIUM) | `bg-yellow-500` | Medium priority task bar fill |
| 低 (LOW)    | `bg-blue-500`   | Low priority task bar fill    |

**Dependency Line Colors:**

| Dependency Type       | Color | Hex          |
| --------------------- | ----- | ------------ |
| FINISH_TO_START (FS)  | 蓝色  | `blue-500`   |
| START_TO_START (SS)   | 绿色  | `green-500`  |
| FINISH_TO_FINISH (FF) | 紫色  | `purple-500` |
| START_TO_FINISH (SF)  | 橙色  | `orange-500` |

**Critical Path Color:**

- Critical path task bar: `ring-2 ring-orange-500`
- Critical path dependency line: `stroke-orange-500`

**Source:** Inherited from Phase 1-4 UI-SPECs; priority colors from D-14, dependency colors from D-08.

## Interaction Contract

### View Toggle Extension

| Property    | Value                                   |
| ----------- | --------------------------------------- |
| Placement   | Task page header, left of CTA           |
| Options     | 列表视图 / 看板视图 / 日历视图 / 甘特图 |
| Trigger     | Click toggle button                     |
| Default     | 列表视图 (可持久化到 taskViewStore)     |
| Persistence | localStorage via Zustand persist        |

**Source:** D-01 from CONTEXT.md — 甘特图作为第四种视图模式.

### Gantt Layout (D-01, D-02, D-03)

| Property           | Value                                    |
| ------------------ | ---------------------------------------- |
| Layout type        | 经典双栏布局                             |
| Left panel         | 固定任务列表 (30%)                       |
| Right panel        | 可滚动时间线区域 (70%)                   |
| Panel split        | 固定比例，不可拖动调整                   |
| Left panel content | 任务名称、状态图标、负责人头像、起止日期 |
| Row alignment      | 左侧每行与右侧时间线条一一对齐           |

**Left Panel Columns:**

| Column   | Width  | Content      |
| -------- | ------ | ------------ |
| 任务名称 | flex-1 | 任务名称文本 |
| 状态     | 60px   | 状态图标     |
| 负责人   | 40px   | 头像         |
| 日期     | 120px  | 起止日期范围 |

**Source:** D-01, D-02, D-03 from CONTEXT.md.

### Time Scale & Navigation (D-04, D-05, D-06)

| Property                 | Value                                        |
| ------------------------ | -------------------------------------------- |
| Scale levels             | 日 / 周 / 月 三级切换                        |
| Default scale            | 日级别 (每列一天)                            |
| Scale header format (日) | Mon, Tue, Wed...                             |
| Scale header format (周) | Week 1, Week 2...                            |
| Scale header format (月) | January, February...                         |
| Time range               | 自动计算 (任务最早 startDate → 最晚 dueDate) |
| Empty range              | 显示当月                                     |
| Panning                  | 鼠标拖拽平移时间线                           |
| Navigation               | 顶部工具栏"今天"按钮快速跳转                 |

**Source:** D-04, D-05, D-06 from CONTEXT.md.

### Dependency Lines (D-07, D-08, D-09, D-10)

| Property       | Value                                              |
| -------------- | -------------------------------------------------- |
| Line style     | 直角折线 (MS Project 风格)                         |
| Line path      | 从源任务条末端 → 折线 → 目标任务条起点             |
| Corner style   | 90度折角                                           |
| Arrow          | 实心三角箭头                                       |
| Arrow position | 连线末端指向被依赖任务                             |
| Line stroke    | 2px                                                |
| Color coding   | 按依赖类型着色 (D-08)                              |
| Hover trigger  | 鼠标悬停连线                                       |
| Hover content  | 弹窗显示: 源任务名称、目标任务名称、依赖类型、状态 |
| Hover delay    | 200ms                                              |

**Dependency Types:**

## Accessibility Contract

| Requirement         | Implementation                                         |
| ------------------- | ------------------------------------------------------ |
| Keyboard navigation | Arrow keys to navigate timeline, Tab through task bars |
| Focus management    | Focus visible on task bars, focus trap in drawer       |
| Screen reader       | Task bar announcements, dependency count per task      |
| Color contrast      | WCAG AA compliant (priority colors verified)           |
| Focus visible       | Focus ring on all interactive elements                 |
| Touch targets       | Minimum 44x44px for touch interactions                 |
