    **3. 创建工具函数文件（src/components/tasks/gantt/utils.ts）**

    实现以下纯函数（无副作用，便于测试）：

    - `calculateTimeRange(tasks: GanttTask[], scaleMode: GanttScaleMode): TimeRange`
      - Per D-05: 根据任务最早 startDate 和最晚 dueDate 自动确定范围
      - 无任务时返回当月范围
      - start/end 各扩展 7 天作为边距
      - 使用 date-fns 的 parseISO, addDays, startOfMonth, endOfMonth, differenceInDays

    - `getTaskPosition(task: GanttTask, timeRange: TimeRange, config: GanttConfig, rowIndex: number, scaleMode: GanttScaleMode): TaskBarPosition | null`
      - 返回 null 如果任务缺少 startDate 或 dueDate
      - x = (task.startDate - timeRange.start) * cellWidth / msPerDay
      - width = (task.dueDate - task.startDate) * cellWidth / msPerDay
      - 最小宽度 20px（当天任务）
      - y = rowIndex * config.rowHeight + (rowHeight - barHeight) / 2

    - `formatScaleDate(date: Date, scaleMode: GanttScaleMode, locale?: string): string`
      - day: 'MM/dd' 或 'M/d'（如 '3/28'）
      - week: '第 N 周'
      - month: 'YYYY年M月'

    - `getPriorityColor(priority: string): string`
      - HIGH/CRITICAL: 'red-500' (#ef4444)
      - MEDIUM: 'yellow-500' (#eab308)
      - LOW: 'blue-500' (#3b82f6)
      - 返回 hex 色值（使用 inline style，Phase 4 已确认 Tailwind v4 不支持 safelist）

    - `getStatusIcon(status: string): string`
      - 返回状态对应的 emoji 或标识符
