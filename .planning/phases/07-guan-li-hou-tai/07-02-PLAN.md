**Create 2 new API route files and update 1 existing:**

1. `src/app/api/v1/admin/projects/route.ts` — NEW FILE (GET + POST):
   - GET: List all projects with member count
     - Auth: checkAdmin pattern (cookies.get('user-id'), role==='ADMIN')
     - Query: `prisma.projects.findMany({ include: { users: { select: { id, name, email } }, _count: { select: { members: true, tasks: true } } }, orderBy: { createdAt: 'desc' } })`
     - Return: `ApiResponder.success(projects)`
   - POST: Create project
     - Body validated with Zod: { name: z.string().min(1), description: z.string().optional(), ownerId: z.string().optional(), startDate: z.string().optional(), endDate: z.string().optional() }
     - Create with `prisma.projects.create({ data: { id: randomUUID(), name, description, status: 'PLANNING', ownerId, startDate, endDate, updatedAt: new Date() } })`
     - Return: `ApiResponder.success(project, '项目创建成功')`

2. `src/app/api/v1/admin/projects/[id]/route.ts` — UPDATE EXISTING:
   - Keep existing DELETE handler
   - ADD PUT handler: Update project
     - Body validated with Zod: { name, description, status, ownerId, startDate, endDate } all optional
     - For archive: status field accepts 'ARCHIVED' (D-06)
     - Update with `prisma.projects.update({ where: { id }, data: { ...validatedData, updatedAt: new Date() } })`
     - Return: `ApiResponder.success(project, '项目更新成功')`

3. `src/app/api/v1/admin/projects/[id]/members/route.ts` — NEW FILE:
   - POST: Add member
     - Body: { userId: string, role: 'PROJECT_OWNER' | 'PROJECT_MEMBER' }
     - Validate with Zod
     - Check user exists, check not already a member
     - Create: `prisma.project_members.create({ data: { projectId: id, userId, role } })`
     - Return: `ApiResponder.success(member, '成员添加成功')`
   - DELETE: Remove member
     - Query param: userId
     - Delete: `prisma.project_members.deleteMany({ where: { projectId: id, userId } })`
     - Return: `ApiResponder.success(null, '成员移除成功')`

All files use: `prisma` from `@/lib/prisma`, `ApiResponder` from `@/lib/api/response`, `zod`, `crypto` for randomUUID. Follow auth pattern from existing projects/[id]/route.ts.
