   - Validate: userIds array max 100 items, status must be valid enum
   - Use `db.users.updateMany({ where: { id: { in: userIds } }, data: { status, updatedAt: new Date() } })`
   - Return: `success({ updatedCount })`

   - PATCH handler
   - Auth: same checkAdmin pattern
   - Body: { userIds: string[], role: UserRole }
   - Validate: userIds array max 100 items, role must be valid enum
   - Use `db.users.updateMany({ where: { id: { in: userIds } }, data: { role, updatedAt: new Date() } })`
   - Return: `success({ updatedCount })`

All files import from: `@/lib/db` (not @/lib/prisma — follow existing pattern from users/route.ts), `@/lib/api/response` (success/error helpers), `zod`, `bcrypt`, `crypto`.
