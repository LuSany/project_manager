  <action>
**Create 3 new files:**

1. `src/lib/auth/permissions.ts` — Permission utility module (D-07, D-08, D-09):
   - Export `checkPermission(userId: string, action: string, resourceType: string, resourceId?: string): Promise<boolean>`
     - RBAC layer (D-08): Check user.role for operation-level permissions:
       - ADMIN → all operations allowed
       - PROJECT_ADMIN → can create/edit/delete projects, tasks
       - EMPLOYEE → can only view and edit own tasks
     - Resource layer (D-08): If resourceId provided, check project_members table:
       - PROJECT_OWNER → full access to project resources
       - PROJECT_MEMBER → view + edit access
       - Non-member → denied (unless ADMIN role)
     - Auto-inheritance (D-09): Project members automatically have 'view' permission on tasks within that project
   - Export `getResourcePermissions(resourceType: string, resourceId: string): Promise<Array<{ userId, userName, role, inherited }>>`
     - Returns all users with access to a resource
     - `inherited` flag is true when permission comes from project membership (D-09)
   - Export `getUserPermissions(userId: string): Promise<Array<{ resourceType, resourceId, resourceName, permission }>>`
     - Returns all resources a user has access to
   - Use prisma from `@/lib/prisma` for all DB queries

2. `src/app/api/v1/admin/permissions/route.ts`:
   - GET: List all permission assignments
     - Auth: checkAdmin
     - Query: type (resource type filter), resource (resource ID filter)
     - Returns: all project_members with user info + role
     - Use: `prisma.project_members.findMany({ include: { user: { select: { id, name, email, avatar } }, project: { select: { id, name } } } })`
   - POST: Create/update permission (add user to project)
     - Body: { userId, projectId, role: 'PROJECT_OWNER' | 'PROJECT_MEMBER' }
     - Upsert: `prisma.project_members.upsert({ where: { id: composite }, create: {...}, update: { role } })`

3. `src/app/api/v1/admin/permissions/[resourceId]/route.ts`:
   - GET: Get permissions for specific resource
     - Returns members of a specific project with their roles
   - DELETE: Remove permission (remove member from project) - Body: { userId } - Delete: `prisma.project_members.deleteMany({ where: { projectId: resourceId, userId } })`
     </action>
