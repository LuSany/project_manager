## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- Kanban column min-width: 280px (任务卡片最小宽度)
- Kanban column gap: 24px (gap-6)
- Kanban card padding: 16px (p-4)
- Task detail drawer width: 480px (fixed width)
- Touch targets: minimum 44x44px (accessibility)

**Source:** Inherited from Phase 1-2 UI-SPECs; kanban-specific values from existing `KanbanBoard.tsx`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page backgrounds, main surfaces |
| Secondary (30%) | `var(--card)` / `var(--popover)` | Kanban columns, list rows, drawer |
| Accent (10%) | `var(--primary)` / `var(--accent)` | Interactive elements |
| Destructive | `var(--destructive)` | Destructive actions only |

**Accent reserved for:**
- Active/selected task row highlight
- Kanban card hover border
- Primary action buttons (新建任务, 保存)
- Focus rings on interactive elements
- Status badges (进行中)

**Status Colors (for badges/indicators):**

| Status | Light Mode | Dark Mode | Usage |
|--------|------------|-----------|-------|
| 待处理 | `bg-muted` | `bg-muted` | 待处理 status badge |
| 进行中 | `bg-brand-500 text-white` | `bg-brand-400` | 进行中 status badge |
| 已完成 | `bg-green-500 text-white` | `bg-green-400` | 已完成 status badge |
| 已阻塞 | `bg-destructive text-white` | `bg-destructive` | 已阻塞 status badge |

**Priority Colors:**

| Priority | Badge Style |
|----------|-------------|
| 高 | `bg-destructive/10 text-destructive border-destructive/20` |
| 中 | `bg-yellow-500/10 text-yellow-600 border-yellow-500/20` |
| 低 | `bg-muted text-muted-foreground` |

**Source:** Inherited from Phase 1-2 UI-SPECs; status/priority colors derived from existing `KanbanCard.tsx` badge patterns and `globals.css` brand tokens.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Keyboard navigation | Full arrow key support in list, tab through cards |
| Drag accessibility | Keyboard drag via Space to pick up, arrows to move, Space to drop |
| Focus management | Focus trap in drawer, restore focus on close |
| Screen reader | Row announcements for sort/filter, card drag announcements |
| Color contrast | WCAG AA compliant (existing color tokens verified) |
| Focus visible | Focus ring on all interactive elements |

## Responsive Behavior

| Breakpoint | Layout |
|------------|--------|
| Desktop (>=1024px) | Full list with sidebar, kanban 3+ columns visible |
| Tablet (768-1023px) | List compact, kanban 2 columns visible |
| Mobile (<768px) | List only (kanban hidden or simplified), drawer full-width |
