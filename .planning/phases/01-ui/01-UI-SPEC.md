## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- Sidebar collapsed width: 64px (w-16) — matches icon-only touch target
- Sidebar expanded width: 256px (w-64) — standard navigation width
- Header height: 56-64px (h-14 to h-16) — per CONTEXT.md specifics
- Touch targets on mobile: minimum 44x44px

**Source:** Pre-populated from shadcn/ui defaults and CONTEXT.md specific ideas

## Interaction Patterns

### Sidebar Collapse Behavior

| State | Width | Content | Interaction |
|-------|-------|---------|-------------|
| Expanded | 256px (w-64) | Icon + Label + Badge | Full navigation |
| Collapsed | 64px (w-16) | Icon only | Tooltip on hover (side: right) |

**Animation:** CSS transition `duration-300 ease-in-out`
**Persistence:** localStorage via Zustand persist middleware
**Source:** CONTEXT.md D-01, D-02, D-03 and existing Sidebar.tsx implementation

### Header Responsive Behavior

| Screen Size | Layout | Elements |
|-------------|--------|----------|
| Desktop (>=768px) | Full width | Breadcrumb + Search + Notification + User menu |
| Mobile (<768px) | Compact | Hamburger menu + Logo + User avatar |

**Position:** Fixed (`sticky top-0`)
**Source:** CONTEXT.md D-04, D-05 and existing Header.tsx patterns

### SSR Hydration Strategy

1. Render skeleton/placeholder before hydration
2. Wait for `_hydrated` state from Zustand persist
3. Apply persisted state (sidebar collapsed/expanded)
4. Prevent layout flash on page refresh

**Source:** RESEARCH.md Pattern 2
