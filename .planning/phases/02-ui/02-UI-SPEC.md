## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets minimum 44px (accessibility requirement)
- Command palette max-height: 400px (existing implementation)

**Source:** Default 8-point scale consistent with existing `globals.css` and `command-palette.tsx` implementation.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page backgrounds, main surfaces |
| Secondary (30%) | `var(--card)` / `var(--popover)` | Cards, sidebar, dropdowns, modals |
| Accent (10%) | `var(--accent)` | Hover states, selected items, focus rings |
| Destructive | `var(--destructive)` | Destructive actions only |

Accent reserved for:
- Command palette item hover/selected states
- Sidebar item hover states
- Focus indicators
- Theme toggle button hover

## Interaction Contract

### Theme Toggle

| Property | Value |
|----------|-------|
| Placement | User menu dropdown (avatar menu in Header) |
| Trigger | Click menu item |
| Animation | CSS transition 150ms ease on `background-color`, `color` |
| Persistence | localStorage via Zustand persist middleware |
| SSR Handling | mounted + _hydrated double-check pattern (same as Phase 1) |

**Theme State Model:**
```typescript
type Theme = 'light' | 'dark' | 'system'
```

**Source:** D-01 (user menu placement), D-02 (extend uiStore), D-03 (localStorage persistence)

### Command Palette

| Property | Value |
|----------|-------|
| Trigger | Cmd+K / Ctrl+K |
| Close | Escape |
| Position | Top 20% centered, max-width 512px |
| Animation | Backdrop fade-in, panel slide-down |

**Command Groups (ordered):**

| Group | Max Items | Icon |
|-------|-----------|------|
| 收藏项目 | 5 | Star |
| 最近访问 | 8 | Clock |
| 快捷操作 | 4 | Plus |
| AI 助手 | 1 | Sparkles |
| 导航 | - | ArrowRight |

**Source:** D-04 (four enhancement areas), existing `command-palette.tsx` structure

### Recent Visits

| Property | Value |
|----------|-------|
| Max records | 8 |
| Storage | localStorage via Zustand persist |
| Record type | `{ id: string, title: string, path: string, timestamp: number }` |
| Sorting | Most recent first |

### Favorites

| Property | Value |
|----------|-------|
| Max records | 5 (display limit) |
| Storage | localStorage via Zustand persist |
| Sorting | Manual order (user can reorder) |
| Toggle | Star icon in page header or command palette |
