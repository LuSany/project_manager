  <files>src/app/projects/[id]/tasks/page.tsx, src/components/tasks/calendar/TaskCalendar.tsx</files>
  <action>
修复拖拽任务到目标日期后截止日期变为前一天的问题。

**根因分析：**
- `tasks/page.tsx` 第 249 行使用 `dueDate.toISOString()` 将本地时间转为 UTC 字符串
- 东八区用户选择 2026-03-27，toISOString() 返回 2026-03-26T16:00:00.000Z
- 后端解析 UTC 字符串存储日期，导致日期偏移

**修复方案：**
在 `src/app/projects/[id]/tasks/page.tsx`:
1. 导入 `format` from 'date-fns'
2. 修改第 249 行：
   ```typescript
   // 修改前
   onUpdateDueDate={(taskId, dueDate) => handleTaskUpdate(taskId, { dueDate: dueDate.toISOString() })}
   // 修改后
   onUpdateDueDate={(taskId, dueDate) => handleTaskUpdate(taskId, { dueDate: format(dueDate, 'yyyy-MM-dd') })}
   ```

3. 同时修改 `handleQuickCreate` 函数（第 144-156 行）：
   ```typescript
   // 修改前
   dueDate: dueDate.toISOString(),
   // 修改后
   dueDate: format(dueDate, 'yyyy-MM-dd'),
   ```

**为什么不使用 setHours(12,0,0,0)：**
- format(date, 'yyyy-MM-dd') 更简洁直接
- 只传日期字符串（不传时间），后端 DateTime 字段会自动处理为当天 00:00
- 避免引入额外的日期操作复杂性
