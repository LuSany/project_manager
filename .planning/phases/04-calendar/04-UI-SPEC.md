## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- Calendar cell size: 48px (--cell-size: 2rem, from existing Calendar component)
- Calendar grid gap: 8px (gap-2)
- Task item in cell: 24px height (h-6), compact single-line display
- No-date task list max-height: 200px (scrollable)
- Touch targets: minimum 44x44px (accessibility)

**Source:** Inherited from Phase 1-3 UI-SPECs; calendar-specific values from existing `calendar.tsx` component.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page backgrounds, main surfaces |
| Secondary (30%) | `var(--card)` / `var(--popover)` | Calendar cells, task bars, drawer |
| Accent (10%) | `var(--primary)` / `var(--accent)` | Interactive elements |
| Destructive | `var(--destructive)` | Destructive actions only |

**Accent reserved for:**
- Today indicator in calendar
- Selected/highlighted date
- Primary action buttons (新建任务, 保存)
- Focus rings on interactive elements
- Drag target highlight

**Priority Colors (for task bars in calendar cells):**

| Priority | Bar Color | Usage |
|----------|-----------|-------|
| 高 (HIGH) | `bg-red-500` | High priority task indicator |
| 中 (MEDIUM) | `bg-yellow-500` | Medium priority task indicator |
| 低 (LOW) | `bg-blue-500` | Low priority task indicator |

**Source:** Inherited from Phase 1-3 UI-SPECs; priority colors from CONTEXT.md specific ideas.

## Interaction Contract

| Options | 列表视图 / 看板视图 / 日历视图 |

### Calendar View Layout

| Property | Value |
|----------|-------|
| Default view | 月视图 (month) |
| View options | 月 / 周 |
| Calendar position | Main content area, full width |
| Navigation | Previous/Next month arrows |

**Source:** D-02 from CONTEXT.md — 默认显示月视图.

### Calendar Cell Design

| Property | Value |
|----------|-------|
| Cell size | 48px x 48px (min) |
| Cell content | Date number + task bars |
| Task bar height | 24px (h-6) |
| Task bar style | Compact, truncate title, priority color indicator |
| Max tasks visible | 3 per cell, overflow shows "+N" |
| Overflow trigger | Click "+N" to expand or open day detail |

**Source:** D-03, D-04 from CONTEXT.md — 紧凑任务条，按截止日期显示.

### Task Display in Cell

| Element | Style |
|---------|-------|
| Task bar container | `h-6 px-1 rounded flex items-center gap-1` |
| Priority indicator | 4px colored dot on left |
| Task title | `text-xs truncate flex-1` |
| Background | `bg-card/80 hover:bg-accent/50` |

### Drag Behavior

| Property | Value |
|----------|-------|
| Drag activation distance | 8px (same as kanban) |
| Drag cursor | `cursor-grab` / `cursor-grabbing` |
| Drag overlay | Task bar with shadow, scale 1.05 |
| Drop target highlight | Date cell bg-accent with border-primary |
| Drop behavior | Immediate dueDate update, no confirmation |
| Drop animation | Fade in at new position |

**Source:** D-05 from CONTEXT.md — 拖拽更新截止日期，直接生效无需确认.

### Quick Create on Date Click

| Property | Value |
|----------|-------|
| Trigger | Click on empty area of date cell |
| Modal type | Popover (inline) or Dialog (mobile) |
| Required fields | 标题 (title) only |
| Optional fields | 优先级, 负责人 |
| Submit | Enter or click 创建 |
| Cancel | Escape or click outside |

**Source:** D-06 from CONTEXT.md — 点击日期快速创建.

### No-Date Task List

| Property | Value |
|----------|-------|

| Collapsible | Yes, collapsed by default |
| Header | "未安排日期 ({count})" |
| Task item style | Similar to kanban card, compact |
| Drag support | Drag to calendar cell to set dueDate |

**Source:** D-07 from CONTEXT.md — 无日期任务显示在日历外列表.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Keyboard navigation | Arrow keys to navigate dates, Enter to select |
| Drag accessibility | Space to pick up task, arrows to move, Space to drop |
| Focus management | Focus trap in quick create dialog, restore on close |
| Screen reader | Date announcements, task count per date |
| Color contrast | WCAG AA compliant (existing color tokens verified) |
| Focus visible | Focus ring on all interactive elements |
