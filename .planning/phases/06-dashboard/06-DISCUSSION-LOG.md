## 图表组件选择与布局

| Option               | Description                          | Selected |
| -------------------- | ------------------------------------ | -------- |
| 环形图 (Donut Chart) | 中间显示总数，外围显示分布，现代感强 | ✓        |
| 饼图                 | 经典饼图，信息密度较低               |          |
| 横向堆叠条形图       | 更节省纵向空间                       |          |

| Option         | Description                    | Selected |
| -------------- | ------------------------------ | -------- |
| 任务完成率对比 | 每个项目显示完成率百分比       | ✓        |
| 多维对比       | 总任务数/已完成/进行中三柱并排 |          |
| 团队效率       | 按成员显示任务完成数           |          |

| Option           | Description                             | Selected |
| ---------------- | --------------------------------------- | -------- |
| 双图组合         | 上方折线图+下方环形图形成概览卡片       | ✓        |
| 保留现有+增强    | 保留 ActivityChart 三线图，增加任务数据 |          |
| 替换为纯任务趋势 | 只显示新增/完成/逾期任务数              |          |

**User's choice:** 环形图 + 任务完成率对比 + 双图组合

**Notes:** 用户选择现代感的环形图用于状态/优先级分布，简洁的完成率对比用于项目对比，折线图+环形图组合形成概览卡片
